Mode Extended Display (Ruang Kerja Diperluas)

Menggabungkan monitor laptop dan layar 4K/Ultrawide eksternal menjadi satu bidang koordinat virtual (5760×2160). Jendela aplikasi dapat digeser (*drag-and-drop*) melintasi batas monitor dengan kalkulasi viewport real-time.

Mode Duplicate / Mirroring (Kloning Tampilan)

Menduplikasi swapchain frame primer ke proyektor atau TV eksternal secara serentak tanpa kompresi visual. Ideal untuk presentasi, panggung, dan demonstrasi profesional.

Kode Surflang Pengatur Topologi Multi-Layar (surf.display):
import surf.display;

component DisplayTopologyPanel: Component {
    @State var mode: DisplayMode = .extended;
    @State var outputs: [DisplayOutput] = DisplayManager.probeOutputs();

    func switchTopology(newMode: DisplayMode) {
        self.mode = newMode;
        // Mengirim wayland frame configuration ke DreX Compositor
        DisplayManager.setTopology(mode: newMode);
    }
}
ARSITEKTUR & PONDASI

Kekuatan Murni Tanpa Kompromi

Surflang memecahkan paradoks klasik antara keanggunan penulisan antarmuka reaktif dan kecepatan biner sistemik.

Affine Borrow Checker

Manajemen memori linear (*Affine Type System*) menjamin *zero memory leaks* dan *zero use-after-free* tanpa jeda Garbage Collection (GC). Memori dibebaskan secara deterministik melalui *RAII Drop Glue*.

Zero Jitter

DreXUI Declarative Reactivity

Sintaks deklaratif elegan terinspirasi dari SwiftUI dan ArkUI, dengan *state-binding* reaktif (@State, @Binding) yang terhubung langsung ke pipeline *Dual-Kawase Acrylic Blur* 240Hz.

240Hz Ready

Hardware Direct Scanout

Integrasi zero-copy DMA-BUF langsung dari buffer aplikasi ke antarmuka KMS/DRM kartu grafis. Latensi render terpangkas drastis menjadi < 0.4 ms pada mode Extreme 240Hz.

Direct DMA-BUF

Landlock LSM v5 Sandboxing

Setiap aplikasi Surflang secara bawaan diisolasi oleh Landlock LSM ABI v5 dan Seccomp-BPF di tingkat kernel. Tidak ada celah akses root atau manipulasi sistem berkas liar.

Military-Grade Security

Kompilasi LLVM & ELF64 Instan

Menghasilkan LLVM IR bersih dan biner eksekutabel ELF64 mandiri untuk arsitektur x86_64 dan ARM64 dalam hitungan milidetik. Siap dikemas menjadi paket Universal Fat .dapp.

x86_64 + ARM64
